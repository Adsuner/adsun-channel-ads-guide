# Adsun Channel Advertising Guide

Public channel setup and sponsored-post lifecycle; no invented channel API.

## What this repository contains

Independent educational example code and public documentation only. It contains no existing Adsun application source, SDK implementation, account tokens, environment files or production data.

## Quick start

Read SETUP.md; no software installation or credentials are needed for this repository.

## Integration and limitations

Channels use @AdsunChannelAdvBot and panel configuration, not the Mini App SDK or an invented HTTP endpoint. Public channels only; review and eligible inventory are required.

## SDK and public sources

- Canonical Mini App SDK URL: https://api.adsun.io/sdk.js
- Official reference: https://adsun.io/documentation/publisher/telegram-channel
- Testing: https://adsun.io/documentation/publisher/testing
